# Bastrio — ‏WebSSH وأسطح المكتب وقواعد البيانات وDocker من المتصفح

[Bastrio (Bastr.io)](https://bastr.io/en/) مساحة عمل في المتصفح لإدارة الخوادم البعيدة. افتح طرفية SSH عبر الويب، وانقل الملفات باستخدام SFTP، واتصل بسطح مكتب RDP أو VNC، واعمل على قواعد البيانات ومضيفات Docker في مكان واحد. تجمع الاتصالات المحفوظة وعلامات التبويب وتقسيم العرض ومساحات الفريق ومساعدة الذكاء الاصطناعي المهام المرتبطة، مع تخزين مشفر لبيانات الاتصال وحماية للحساب.

## مساحة عمل تتبع المهمة

اتصل بمضيف، وافتح الطرفية، وراجع ملف إعدادات، واستعلم من قاعدة البيانات، ثم افحص حاوية دون إعادة تجهيز سياق الاتصال في تطبيقات متعددة. يبقي الشريط الجانبي للمضيفات وعلامات التبويب وتقسيم العرض الأدوات قريبة من المهمة.

![مساحة Bastrio مع طرفية SSH ومدير ملفات SFTP في عرض مقسم](../images/readme/split-workspace.png)

| القسم | ما يمكنك فعله من الواجهة |
| --- | --- |
| المضيفات والجلسات | حفظ الاتصالات وتنظيم المجلدات والتصفية حسب النوع وفتح الجلسات الأخيرة وترتيب علامات التبويب أو تقسيم العرض. |
| WebSSH والأوامر البعيدة | استخدام كلمة مرور أو مفتاح SSH، وطرفية المتصفح والأوامر السريعة والبحث وإعادة الاتصال. تتوفر أنواع WinRM وTelnet عند تفعيلها. |
| SFTP وFTP وFTPS | تصفح المجلدات ورفع الملفات وتنزيلها وإنشاء المجلدات وإعادة التسمية وتحرير الملفات النصية المدعومة بجانب الطرفية. |
| RDP وVNC | فتح سطح المكتب في المتصفح مع أدوات الجلسة والحافظة واختصارات لوحة المفاتيح. يجب أن يوفر الهدف خدمة RDP أو VNC يمكن الوصول إليها. |
| قواعد البيانات | الاتصال بـ PostgreSQL وMySQL/MariaDB وSQL Server وRedis وMongoDB، واستخدام أدوات التصفح والاستعلام والتحرير والنسخ الاحتياطي المتاحة لكل محرك. |
| Docker | إضافة مضيف SSH موجود واكتشاف الحاويات وعرض استهلاك الموارد والعمل مع Compose والصور ووحدات التخزين والشبكات. النشر عبر قوالب التطبيقات أو الصور المخصصة أو إعدادات Compose المدعومة. |
| مسارات الشبكة | اختيار مسار وكيل إقليمي متاح، أو إعداد وكيل خاص بك، أو استخدام مضيف قفز SSH. |
| مساحات الفريق | التنقل بين المساحات الشخصية والمشتركة ودعوة الأعضاء ومنح الوصول إلى موارد محددة. |
| الذكاء الاصطناعي وMCP | طلب المساعدة بجوار الطرفية أو قاعدة البيانات، أو ربط عميل MCP بالموارد التي تسمح له بالوصول إليها. |
| الأدلة التشغيلية المشفرة والتخزين | تنظيم مستندات العمل وتشفير الملاحظات الحساسة بكلمة مرور مستقلة وإدارة الملفات ضمن المساحة المتاحة. |

يعتمد توفر البروتوكولات وإجراءات Docker والكتابة في قواعد البيانات واستخدام الذكاء الاصطناعي والتخزين على الحساب وصلاحيات مساحة العمل والخدمة المستهدفة. تعرض الواجهة الإمكانات المتاحة لجلسة العمل.

## التشفير والتحكم في الوصول

- **تشفير بيانات الاتصال:** تُحمى كلمات المرور والمفاتيح الخاصة المحفوظة بتشفير AES-256-GCM أثناء التخزين.
- **حماية النقل:** استخدم Bastr.io عبر HTTPS، واختر بروتوكول اتصال مشفرًا مناسبًا للهدف، مثل SSH/SFTP أو FTPS.
- **حماية الحساب:** فعّل المصادقة الثنائية واحتفظ بمفتاح الاسترداد دون اتصال بالإنترنت. يساعد مسار الاسترداد على استعادة الوصول إلى بيانات الاتصال المشفرة بعد إعادة تعيين كلمة المرور.
- **كلمة مرور مستقلة للمستند:** اختر وضع التشفير وحدد كلمة مرور خاصة بالمستند، ثم أكد التشفير والحفظ في المحرر. احتفظ بكلمة المرور في مكان آمن.
- **صلاحيات الذكاء الاصطناعي:** تدعم مفاتيح API الخاصة بـ MCP صلاحيات محددة وتاريخ انتهاء وإلغاء الوصول. راجع طلبات الموافقة في المتصفح وأدر بيانات اعتماد الخوادم من واجهة مساحة العمل.

تعمل هذه الحماية مع صلاحيات الأنظمة البعيدة وإعداداتها الأمنية. احتفظ ببيانات الاعتماد الحقيقية ومواد الاسترداد خارج المستندات المشتركة ولقطات الشاشة ومحادثات الذكاء الاصطناعي.

## بدائل أدوات SSH وقواعد البيانات وDocker

إذا كنت تبحث عن بديل لـ Termius، أو طريقة للعمل في المتصفح بدلًا من FinalShell أو Xshell، أو عميل قواعد بيانات يشبه Navicat، أو بديل لـ Portainer لإدارة Docker عبر SSH، فابدأ بالمهمة المطلوبة. يناسب Bastrio جمع موارد بعيدة متعددة في سير عمل مشترك من المتصفح.

| أدوات قد تقارن بينها | متى تفكر في Bastrio؟ | الدليل بالإنجليزية |
| --- | --- | --- |
| Termius وFinalShell وMobaXterm وXshell وSecureCRT وPuTTY | عندما تريد SSH من المتصفح ومضيفات محفوظة وجلسات مقسمة وأدوات ملفات قريبة. قيّم متطلبات سكربتات سطح المكتب وX11 بصورة منفصلة. | [أدوات SSH](../articles/en/ssh-tools-browser-workspace.md) |
| WinSCP وFileZilla وXftp وCyberduck | لنقل الملفات عبر SFTP أو FTP/FTPS وتحرير النصوص بجوار الجلسة البعيدة. | [سير عمل FTP/SFTP](../articles/en/ftp-sftp-tools-browser-workflow.md) |
| Navicat وDBeaver وDataGrip وpgAdmin وRedis Insight وMongoDB Compass | لعميل قواعد بيانات في المتصفح بجانب المضيفات، وفق احتياجات المحرك والاستعلام والتحرير والنسخ الاحتياطي. | [قواعد البيانات البعيدة](../articles/en/remote-database-tools-comparison.md) |
| Apache Guacamole وTeamViewer وAnyDesk وToDesk | للوصول من المتصفح إلى خدمة RDP/VNC موجودة. تختلف متطلبات الاتصال بين المساعدة عن بُعد وبوابات سطح المكتب. | [أسطح المكتب البعيدة](../articles/en/browser-remote-desktop-tools.md) |
| Portainer وDockge وDocker Desktop | لإدارة Docker وCompose عن بُعد عبر مضيف SSH موجود. التطوير المحلي وإدارة العناقيد لهما متطلبات تقييم مستقلة. | [Docker حسب السيناريو](../articles/en/docker-management-tools-by-scenario.md) |
| MCP مع SSH وقواعد البيانات وDocker | لعميل ذكاء اصطناعي يعمل على موارد مصرح بها مع صلاحيات وضوابط موافقة. | [الإدارة عبر MCP](../articles/en/mcp-remote-management-tools.md) |

تركز المقارنة على أساليب العمل. تختلف الإمكانات باختلاف المنتج والإصدار والإعدادات؛ وتوضح الأدلة أيضًا متى تكون الأداة المتخصصة أنسب.

## ابدأ من المتصفح

1. زر [bastr.io](https://bastr.io/en/). استخدم اتصال الضيف المتاح لجلسة مؤقتة أو سجل الدخول لحفظ موارد العمل.
2. اختر البروتوكول من **Quick Connect** أو أضف الهدف في **Hosts**. أدخل كلمات المرور والمفاتيح الخاصة في نموذج الاتصال فقط.
3. اختر وكيلًا أو مضيف قفز SSH عندما يحتاج الهدف إلى مسار شبكة محدد.
4. افتح الجلسة واستخدم **Files** أو لوحة قاعدة البيانات أو **Docker** للخطوة التالية. رتّب الجلسات المرتبطة بأدوات التخطيط.
5. للعمل الجماعي، اختر مساحة العمل المناسبة وشارك الموارد اللازمة. فعّل المصادقة الثنائية واحتفظ بمواد الاسترداد.

لوصول الضيف توفر وحدود خاصة به. تتطلب الاتصالات المحفوظة وبعض الأدوات وميزات الفريق تسجيل الدخول أو حسابًا مؤهلًا.

## إدارة Docker عبر SSH

افتح **Docker** واختر مضيف SSH تستطيع الوصول إليه. تجمع الواجهة الحاويات ومشاريع Compose والصور ووحدات التخزين والشبكات وتقدم المهام. يمكنك مراجعة الحالة واستهلاك الموارد وتنفيذ إجراءات دورة الحياة المدعومة والبدء بالنشر باستخدام قوالب التطبيقات أو صورة مخصصة أو إعداد Compose مدعوم.

إذا لم يكن Docker مثبتًا، يمكن للواجهة إرشادك إلى تثبيته على مضيف Linux مدعوم بعد مراجعة الإجراء وتأكيده. يعتمد ذلك على المضيف والصلاحيات وإتاحة الميزة. اقرأ [دليل Docker بالإنجليزية](../articles/en/docker-management-tools-by-scenario.md).

## ربط عملاء الذكاء الاصطناعي عبر MCP

يدعم Bastrio بروتوكول سياق النموذج Model Context Protocol (MCP) لربط عملاء مثل Claude Code وCodex وCursor وVS Code. وإلى جانب المساعد المدمج، يستطيع العميل الذي تختاره العمل مع المضيفات والملفات وقواعد البيانات ومسارات الشبكة المصرح بها.

1. افتح **Tools → MCP API Keys**.
2. أنشئ مفتاحًا بالصلاحيات ومدة الصلاحية المطلوبة.
3. اختر العميل واتبع تعليمات الاتصال المعروضة في الصفحة.
4. احتفظ بالمفتاح في إعدادات الأسرار أو متغيرات البيئة التي يدعمها العميل. راجع الموافقات في المتصفح وألغِ الوصول عند انتهاء الحاجة إليه.

استخدم عنوان الخدمة المعروض في حسابك. يكتشف العميل الأدوات المتاحة من خدمة MCP وفق الصلاحيات الممنوحة. اقرأ [دليل MCP بالإنجليزية](../articles/en/mcp-remote-management-tools.md).

## أسئلة شائعة

### ما هو Bastrio؟

مساحة عمل في المتصفح تجمع WebSSH ونقل الملفات وRDP/VNC وقواعد البيانات وإدارة Docker والموارد المشتركة ومساعدة الذكاء الاصطناعي للمطورين والمشغلين.

### هل يمكن أن يحل محل Termius أو FinalShell أو MobaXterm؟

يوفر أسلوبًا في المتصفح لمهام SSH وإدارة الملفات الشائعة. تحقق قبل الانتقال من احتياجات التكامل مع الطرفية المحلية والماكرو وX11. يساعدك [دليل SSH بالإنجليزية](../articles/en/ssh-tools-browser-workspace.md) في الاختيار حسب الاستخدام.

### هل هو بديل في المتصفح لـ Navicat أو DBeaver؟

يمكنه تلبية مهام شائعة في PostgreSQL وMySQL/MariaDB وSQL Server وRedis وMongoDB. تتغير العمليات بحسب المحرك والصلاحيات؛ قيّم النمذجة المتقدمة والمزامنة والتطوير المتخصص وفق متطلباتك.

### هل هو بديل لـ Portainer؟

يمكن تقييمه لإدارة مضيفات Docker وCompose بجانب SSH والملفات وقواعد البيانات عبر اتصال SSH موجود. قارن [دليل Docker بالإنجليزية](../articles/en/docker-management-tools-by-scenario.md) باحتياجات بيئتك.

### هل أحتاج إلى تثبيت عميل لسطح المكتب؟

يمكنك استخدام مساحة العمل من متصفح مدعوم. يجب أن يوفر الهدف خدمة بعيدة يمكن الوصول إليها وبيانات اعتماد صالحة.

### كيف تُحمى بيانات الاتصال والملاحظات الحساسة؟

تُشفّر بيانات الاتصال المحفوظة باستخدام AES-256-GCM أثناء التخزين، ويستخدم الموقع HTTPS. تدعم المستندات الحساسة الحفظ المشفر بكلمة مرور مستقلة، مع ضوابط إضافية للمصادقة الثنائية والاسترداد وصلاحيات الموارد.

### هل يمكن البدء دون حساب؟

استخدم اتصال الضيف عندما تعرضه الصفحة الرئيسية. قد تتغير البروتوكولات والحدود الزمنية؛ سجل الدخول لحفظ الاتصالات واستخدام الأدوات المتاحة لحسابك.
