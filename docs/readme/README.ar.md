## مساحة عمل واحدة للبنية التحتية البعيدة

يجمع [Bastrio](https://bastr.io/) بين **SSH عبر الإنترنت** وSFTP وFTP/FTPS وRDP وVNC واتصالات قواعد البيانات في مساحة عمل واحدة داخل المتصفح. استخدمه كطرفية SSH ويب، ومدير ملفات عبر الإنترنت، وعميل قواعد بيانات في المتصفح، ومساحة مشتركة لإدارة الخوادم البعيدة.

![Bastrio SSH عبر الإنترنت والوصول البعيد من المتصفح](../images/readme/ssh-online-guest.png)

## الإمكانات الأساسية

- **اتصل من المتصفح:** طرفية SSH عبر الإنترنت، وملفات SFTP/FTP/FTPS، وسطح المكتب البعيد RDP وVNC.
- **أدوات قواعد بيانات موحدة:** PostgreSQL وMySQL/MariaDB وSQL Server وRedis وMongoDB في مساحة العمل نفسها.
- **نظّم الاتصالات:** اتصالات محفوظة ومجلدات وفلاتر حسب النوع وآخر الاتصالات وجلسات متعددة وتخطيطات مقسمة.
- **اختر مسار الشبكة:** عنوان IP وكيل حسب المنطقة، أو وكيل مخصص، أو مضيف قفز SSH للبنية التحتية غير المكشوفة مباشرة.
- **مساعدة الذكاء الاصطناعي:** يساعد مساعد الذكاء الاصطناعي في تفسير المخرجات وكتابة الأوامر ومهام الطرفية وقواعد البيانات.
- **مساحات عمل تعاونية:** تحافظ مساحات العمل والموارد المشتركة على سياق اتصال الفريق.
- **مستندات تشغيل مشفرة:** اكتب وشفر واحفظ الملاحظات والمسودات والنصوص الحساسة داخل مساحة العمل.

## مسارات شبكة تحت سيطرتك

يتيح Bastrio اختيار المسار الملائم لكل وصول بعيد من المتصفح: اختر **عنوان IP وكيل** عند الحاجة إلى منطقة خروج، أو اضبط وكيلاً مخصصاً للتحكم بالمسار، أو استخدم **مضيف قفز SSH** للوصول إلى بنية تحتية خاصة. هذه الخيارات جزء من إعداد الاتصال نفسه.

## عمل بعيد مركز وتعاوني

Bastrio مساحة عمل بعيدة للمطورين وفرق التشغيل والفرق التي تنتقل بين الخوادم والملفات وسطح المكتب وقواعد البيانات. تحافظ مساحات العمل والموارد المشتركة على السياق، وتبقي الجلسات المتعددة والتخطيطات المقسمة العمل المرتبط ظاهراً، ويبقى مساعد الذكاء الاصطناعي قريباً من المهمة.

## الخصوصية حسب التصميم

تُشفّر بيانات الاعتماد ومحتوى مساحة العمل الخاص أثناء النقل وأثناء التخزين. لا يفك Bastrio تشفير بيانات الاعتماد إلا مؤقتاً في الذاكرة المتطايرة للخادم عندما تتطلبها عملية مصرح بها؛ ولا تُكتب النصوص الواضحة على القرص أو في السجلات. يتطلب كل وصول ظاهر للمستخدم جلسة مصادقة صالحة. عند انتهاء جلسة أو إلغائها، لا يمكن بعد ذلك الوصول إلى الخزنة المشفرة أو فك تشفيرها. يُعرض مفتاح الاسترداد مرة واحدة فقط؛ ويلزم لاستعادة بيانات الاعتماد المشفرة بعد إعادة تعيين كلمة المرور. من دونه لا يمكن استرداد الخزنة المشفرة أو تصديرها بصيغة قابلة للقراءة.

## Marketplace، مخطط له

يُعِد Bastrio سوقاً للخوادم المُدارة وخدمات عناوين IP الوكيلة. هذه العروض مخططة لإصدار مستقبلي وليست خدمات متاحة حالياً.

## ابدأ الاستخدام

1. تفضل بزيارة [bastr.io](https://bastr.io/) لفتح مساحة عمل Bastrio البعيدة.
2. اختر SSH أو نقل الملفات أو سطح المكتب البعيد أو اتصال قاعدة بيانات.
3. اختر مسار الشبكة عند الحاجة، ثم احفظ الاتصال ونظمه للعمل اللاحق.

## أسئلة شائعة

### هل Bastrio طرفية SSH ويب؟

نعم. يقدم Bastrio SSH عبر الإنترنت في المتصفح إلى جانب نقل الملفات وسطح المكتب البعيد وقواعد البيانات والوكيل وأدوات مساحة العمل.

### هل يمكنني استخدام عنوان IP وكيل ووكيل مخصص ومضيف قفز SSH؟

نعم. يدعم Bastrio اختيار عنوان IP وكيل حسب المنطقة وإعداد وكيل مخصص ومضيفات قفز SSH.

### هل يمكن للفريق التعاون في البيئة نفسها؟

نعم. صُممت مساحات العمل والموارد المشتركة للحفاظ على تنظيم عمل البنية التحتية البعيدة وتعاونه.
