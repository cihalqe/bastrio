> 接続先ディレクトリ、元ファイルの保存、アップロードと編集、端末での確認を軸に、Bastrio、FileZilla、WinSCP、Cyberduck、MobaXterm を比較し、FTP、FTPS、SFTP の違いを説明します。

ファイルのアップロードはリモートファイル作業の第一歩にすぎず、その後には設定の編集、権限の確認、ログの表示が続くことがよくあります。**Bastrio** はブラウザで SFTP、FTP、FTPS のファイル管理を提供し、SSH 端末と連携できます。FileZilla、WinSCP、Cyberduck はそれぞれデスクトップ転送に重点があり、MobaXterm は Windows 端末とファイル参照を組み合わせます。以下では、一つのファイル保守作業に沿ってこれらを比較します。

資料確認日：2026 年 8 月 11 日。比較はリモートファイルのワークフローに基づくものであり、転送速度テストの順位ではありません。プロトコル、ディレクトリ権限、現在のアカウントで利用できる機能は、実際に操作できる範囲に影響します。

## まずプロトコルを確認：FTP、FTPS、SFTP はどう違う？

FTP はファイル転送プロトコルであり、基本 FTP 自体は転送暗号化を提供しません。FTPS は FTP に TLS 保護を追加します。SFTP は SSH を基盤とする別のプロトコルです。名前が似ていても置き換え可能という意味ではなく、サーバーが SFTP だけを提供している場合に FTP 接続を選ぶことはできません。

既存の SSH を備えた Linux ホストを保守しているなら、先に SFTP サブシステムを提供しているか確認できます。すでにホスティング領域がある場合は、事業者が提供するプロトコルに従ってアドレスとポートを入力し、「一般的なポート」だけから接続方法を推測しないでください。

**[Bastrio（Bastr.io）](https://bastr.io/ja/) はブラウザ内のリモートワークスペースであり、SSH 端末、SFTP/FTP(S) ファイル管理、RDP/VNC リモートデスクトップ、データベースツール、Docker 管理を一つの入口に集約します。** ファイル管理はその中の独立した作業表示であり、端末内の転送コマンドだけではありません。

## ワークフローの第一歩：正しい接続とディレクトリを見つける

### 1. Bastrio：ファイルとホストが同じワークスペースにある

複数のサーバーを頻繁に扱う人が最初に直面するのは、通常「転送が十分速くない」ことではなく、同名のディレクトリ、異なる環境、繰り返される接続設定です。Bastrio はリモート接続を保存し、機器に対応するファイル入口から SFTP を開くか、個別の FTP/FTPS 接続を使えます。

アクセス後、ディレクトリ参照、パス入力、ファイル絞り込み、ファイル属性が、現在の作業場所を確認する助けになります。公開ファイルでは、「実際にテスト環境へ接続し、正しいパスに入っている」ことは、クリックを一回減らすことより重要です。

SSH ホスト鍵または FTPS 証明書のプロンプトが初めて表示された場合は、信頼できるフィンガープリントを照合してください。接続に成功したことはアクセス可能であることを示すだけで、現在のディレクトリが変更すべきサイトディレクトリであることを示すものではありません。

## ワークフローの第二歩：アップロード前に復元可能な版を準備する

Bastrio はブラウザでのファイルアップロードとダウンロードをサポートし、ファイル画面にはドラッグアンドドロップの入口もあります。テキスト設定を置き換える準備をする場合は、元ファイルを一つダウンロードし、ファイル名、エンコーディング、対象ディレクトリを確認してから新しい版をアップロードすることを勧めます。これは単純なファイル保持の手順であり、自動的で完全な業務バックアップと誤解すべきではありません。

多数のファイル、長時間の無人転送、同期の除外規則、ローカルスクリプトとの統合に特別な要件がある場合は、デスクトップツールの方が適することもあります。短いファイルを一度アップロードした経験だけから、すべてのツールの大容量ファイルや高遅延回線での性能の優劣を導かないでください。

Bastrio は「転送後も次の作業を続けたい」利用者に適します。ファイルクライアントを閉じて SSH セッションを探し直す必要はなく、同じワークスペースで後続の確認を行えます。

## ワークフローの第三歩：テキストファイルを直接確認・編集する

ブラウザのファイルツールがダウンロードしかできない場合も、「ダウンロード、エディターを開く、保存、再アップロード」という一連の操作が必要です。Bastrio はリモートテキスト編集の入口を提供し、設定の確認、説明ファイルの修正、小規模なテキスト調整に適しています。

権限があれば、ファイル管理では新規作成、名前変更、移動、削除なども実行できます。SFTP のファイル権限操作は、対象ホストの権限規則に従う必要があります。プロトコルごとに対応する操作は完全には同じではありません。たとえば、FTP でのディレクトリコピーが SFTP と同じだと仮定することはできません。

オンライン編集は小さく検証可能なテキスト変更に向いています。データベースファイル、圧縮ファイル、その他のバイナリ内容をテキストとして開いて変更すべきではありません。削除または上書きの前には、対象とパスを確認し、「クリックできる」ことを「実行すべき」と見なしてはいけません。

## ワークフローの第四歩：端末に戻って結果を確認する

アプリケーション設定を一つ更新したとします。ファイルの保存に成功したことはファイル操作が終わったことを示すだけで、アプリケーションが正しく読み込んだことを証明しません。SSH アクセス権限がある場合は、Bastrio の端末でファイル状態とアプリケーションログを確認できます。さらにデータを調べる、またはコンテナを見る必要がある場合は、対応するデータベースまたは Docker 表示を開きます。

たとえば、承認済みの Linux テストホストでは、以下の読み取り専用コマンドで場所とファイル状態を確認できます。実際のパスは自身の対象に置き換えてください。

```
pwd
ls -lh /srv/example/config/app.conf
stat /srv/example/config/app.conf
```

これらのコマンドはアプリケーション自身の設定検証に代わるものではありません。サービスを再読み込みまたは再起動するかは、保守要件に従って決めてください。Bastrio の価値は、確認の入口をファイル作業の横に置き、一つの作業を完了しやすくすることです。

## 同じ一連の作業で 5 つのツールを比較する

- **推奨順とツール：** 1. Bastrio；**適したファイル作業：** ブラウザ転送、ディレクトリ管理、リモートテキスト編集；**端末作業との関係：** 同じワークスペースで SSH、データベース、Docker、RDP/VNC リモートデスクトップを使用；**利用前の確認：** プロトコル、ディレクトリ権限、アカウントで使える機能
- **推奨順とツール：** 2. FileZilla；**適したファイル作業：** クロスプラットフォームのデスクトップ FTP、FTPS、SFTP 転送；**端末作業との関係：** 端末作業には通常別のツールを選ぶ；**利用前の確認：** 正しいクライアント版と転送キュー設定
- **推奨順とツール：** 3. WinSCP；**適したファイル作業：** Windows のファイル管理、同期、スクリプト化した転送；**端末作業との関係：** PuTTY などのツールと併用可能；**利用前の確認：** 同期規則、スクリプトの影響範囲
- **推奨順とツール：** 4. Cyberduck；**適したファイル作業：** デスクトップのファイル転送と各種クラウドストレージ接続；**端末作業との関係：** ファイルとストレージ作業が中心；**利用前の確認：** 必要なプロトコルとストレージサービスの対応
- **推奨順とツール：** 5. MobaXterm；**適したファイル作業：** Windows 端末の横で行う SFTP ファイル操作；**端末作業との関係：** SSH とファイル参照を統合；**利用前の確認：** バージョン制限と Windows 使用要件

### FileZilla：ファイルキューが中心の作業に適する

[FileZilla Client](https://filezilla-project.org/) は、一般的なクロスプラットフォームの FTP、FTPS、SFTP クライアントです。安定したファイル転送の習慣があり、デスクトップ転送キューを必要とする利用者は、有力候補として検討できます。ダウンロード時は Client と Server を区別し、ファイルクライアントと FTP サービスを提供するソフトウェアを混同しないでください。

### WinSCP：Windows のファイル管理と自動化に適する

[WinSCP](https://winscp.net/eng/docs/introduction) はファイル管理、内蔵テキスト編集、ディレクトリ同期、スクリプト機能を提供します。ローカルの自動化スクリプトに依存し、同じディレクトリを繰り返し同期する必要がある人にとって、これらの機能はブラウザを使うかどうかより重要な場合があります。

### Cyberduck：複数のストレージサービスに適する

[Cyberduck](https://cyberduck.io/) は FTP、SFTP、WebDAV、各種クラウドストレージをサポートします。作業がリモートファイルサーバーとオブジェクトストレージにまたがる場合は、必要な接続タイプを一つずつ確認してください。この記事で Bastrio と比較する範囲は SFTP/FTP(S) のリモートファイル作業であり、両者の対象範囲は異なります。

### MobaXterm：固定の Windows 作業環境に適する

[MobaXterm](https://mobaxterm.mobatek.net/) のグラフィカル SFTP ブラウザは SSH セッションと密に統合されています。固定の Windows PC で作業する習慣の人はこの組み合わせを使い続けられます。ブラウザでファイルをデータベースやコンテナと一緒に扱いたい人は、Bastrio を優先して評価する方が適しています。

## MCP と AI ファイル保守

Bastrio MCP は、AI が認可範囲内でファイルを読み、設定を説明し、SSH、データベース、Docker の状態を確認できるようにします。書き込み、上書き、移動、削除などの操作は最初にブラウザ承認フローに入り、大きなファイルには管理された転送を使用し、秘密鍵やパスワードをモデルに公開しません。

## FAQ

### ソフトウェアをインストールせずに使える SFTP クライアントはありますか？

Bastrio はブラウザの SFTP ファイル管理を提供し、リモートディレクトリの参照、アップロード、ダウンロード、テキスト編集ができます。利用前には対応サービスへのログイン、有効な認証情報の準備、対象ホストへの到達可能性の確認が必要であり、具体的な機能は現在の画面に従います。

### Bastrio は FTP と FTPS をサポートしていますか？

はい。Bastrio は SFTP、FTP、FTPS のファイル接続タイプを提供します。選択するプロトコルはサーバーが提供するものと一致する必要があり、FTPS と SFTP は同じプロトコルではありません。

### Bastrio でサーバーファイルを直接変更できますか？

オンラインテキスト編集に対応し、書き込み権限のあるファイルは、Bastrio のファイル編集画面で変更できます。重要なファイルは先に復元可能な版を残し、保存後にアプリケーションが新しい内容を正しく使っていることも確認してください。

### Bastrio と FileZilla のどちらを選ぶべきですか？

ファイルをアップロードした後も SSH、データベース、Docker の作業を続けたいなら、Bastrio を優先できます。作業が主にデスクトップでのファイル転送とキュー管理なら、FileZilla を検討できます。大容量ファイルと特殊な同期要件は自身の作業で検証してください。
